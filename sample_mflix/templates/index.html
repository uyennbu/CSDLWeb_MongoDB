MongoDB Sharding Cluster

Sharding (Phân mảnh): Chia nhỏ tập dữ liệu 21.349 phim ra 3 Shard độc lập dựa trên Shard Key: year. Client chỉ làm việc với mongos router, mongos tra cứu metadata trên Config Server (cfgRS) để chuyển tiếp truy vấn.

Sơ đồ luồng truy vấn Sharded Cluster:
Client / Web App ──▶ mongos (Router) ──[Tra cứu Metadata]──▶ Config Server (cfg1:27017)
                      ├── [year < 1980]   ──▶ Shard 1 (shard1RS)
                      ├── [1980..2000)  ──▶ Shard 2 (shard2RS)
                      └── [year >= 2000]──▶ Shard 3 (shard3RS)
